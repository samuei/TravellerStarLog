# [TravellerStarLog](https://samuei.github.io/TravellerStarLog)
 A visual guide to your Traveller RPG universe.

This project can be freely used via the Github Pages link above, but if you'd prefer to pull it down locally, you should use the following command:

`git clone --recursive https://github.com/samuei/TravellerStarLog`

This is due to the project's reliance on the fantastic work of [Open Innovations](https://open-innovations.org/) on their [Hexmap](https://github.com/open-innovations/oi.hexmap.js) project, which is included as a git submodule. See [here](https://github.blog/2016-02-01-working-with-submodules/) for more information on managing submodules.

Once you have the project and its submodule, you should be able to `npm install` and then `npm run dev` to see the project in your [local browser](http://localhost:5173)!
